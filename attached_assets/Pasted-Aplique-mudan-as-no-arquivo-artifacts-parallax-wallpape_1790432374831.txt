Hoje a rolagem da Composição dispara os pulses (middlePicker,
foregroundPicker, previewButton) via setTimeout(..., 780) fixo, que
foi calibrado para a rolagem antiga de 900ms. Agora que a rolagem
usa duração adaptativa (360–620ms), o timing fica dessincronizado.

Solução: em vez de timeout fixo, amarrar os pulses ao FIM REAL da
rolagem, via callback opcional em animateScrollTo.

═══════════════════════════════════════════════
MUDANÇA 1 — animateScrollTo aceita callback de conclusão
═══════════════════════════════════════════════

A assinatura atual de animateScrollTo é:

  const animateScrollTo = useCallback(
    (
      scrollRef: React.MutableRefObject<ScrollView | null>,
      currentYRef: React.MutableRefObject<number>,
      frameRef: React.MutableRefObject<number | null>,
      targetY: number,
    ) => {

Adicione um quinto parâmetro opcional:

      onComplete?: () => void,

E, dentro do step, no ramo em que a rolagem termina (onde hoje está
"currentYRef.current = targetY; frameRef.current = null;"), chame o
callback depois de zerar o frame:

      } else {
        currentYRef.current = targetY;
        frameRef.current = null;
        onComplete?.();
      }

NÃO altere mais nada dentro de animateScrollTo.

═══════════════════════════════════════════════
