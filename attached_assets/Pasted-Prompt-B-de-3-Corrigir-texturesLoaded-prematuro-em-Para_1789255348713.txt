PROBLEMA:
A flag `texturesLoaded` é marcada como true ANTES de verificar se o JSON existe e ANTES de tentar carregar. Se a primeira chamada ocorrer quando o JSON ainda não estiver disponível (por exemplo, timing entre o `apply()` do SharedPreferences e a leitura da thread EGL), o manager fica marcado como "carregado" para sempre, mesmo sem nenhuma textura. Chamadas subsequentes retornam cedo sem tentar de novo.

CORREÇÃO:
Mover a atribuição `texturesLoaded = true;` de onde está hoje (logo após o `if (texturesLoaded) return mTextureIds;`) para o FINAL do bloco `try`, imediatamente após o `for` que carrega as camadas e antes do `catch`. Assim a flag só é marcada quando o JSON foi lido e o loop de carregamento completou sem exceção.
