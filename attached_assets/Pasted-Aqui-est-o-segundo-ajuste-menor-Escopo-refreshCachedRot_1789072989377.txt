Aqui está o segundo ajuste menor.

Escopo
refreshCachedRotation() passa a retornar boolean indicando se a rotação mudou desde a última chamada.

Novo método invalidateSensorCalibration().

onConfigurationChanged() chama refreshCachedRotation() e, se a rotação mudou, invalida a calibração.

Chamadas existentes no construtor e em onVisibilityChanged continuam funcionando — só ignoram o retorno.

Trecho 2 — Substituir onConfigurationChanged
Substitua o método atual:

    }
por:

java
    @Override
    public void onConfigurationChanged(Configuration newConfig) {
      super.onConfigurationChanged(newConfig);
      boolean rotationChanged = refreshCachedRotation();
      if (rotationChanged) {
        invalidateSensorCalibration();
        Log.i(TAG, "PARALLAX_SENSOR_CALIBRATION_INVALIDATED reason=rotation_changed");
      }
    }
Justificativa
refreshCachedRotation() remapeia corretamente os eixos X/Y do sensor para a nova rotação.

Mas baselinePitch e baselineRoll foram calculados com o remapeamento antigo. Após girar o aparelho, o valor "neutro" muda — sem recalibrar, o parallax fica deslocado até o usuário esconder/mostrar o wallpaper (que já chama invalidateSensorCalibration indiretamente via onVisibilityChanged(true) zerando os mesmos campos).

Ao invalidar apenas quando a rotação realmente mudou, evitamos recalibrar em chamadas espúrias de onConfigurationChanged (que também pode disparar por mudança de locale, densidade, etc.).

O sensor listener roda na main thread (registerListener sem Handler), o mesmo contexto de onConfigurationChanged, então não há race nova nos campos de calibração.

Verificação
☑ refreshCachedRotation() ainda atualiza cachedRotation, cachedAxisX, cachedAxisY.
☑ Retorno boolean é ignorado no construtor e em onVisibilityChanged — sem warning de variável não usada, pois são chamadas de método.
☑ onConfigurationChanged só invalida quando a rotação muda.
☑ Após invalidação, o próximo onSensorChanged reentra no bloco if (!calibrated) e refaz a calibração com os eixos já remapeados.
☑ Log novo PARALLAX_SENSOR_CALIBRATION_INVALIDATED é útil para diagnostico e ocorre com baixa frequência (apenas em rotação).
