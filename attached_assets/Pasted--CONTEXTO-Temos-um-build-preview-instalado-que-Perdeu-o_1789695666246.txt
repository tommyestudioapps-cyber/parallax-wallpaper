TAREFA 2 — Tornar o app debuggable no profile preview
────────────────────────────────────────────────
No arquivo .eas.json, adicione ao profile "preview" a opção:
  "android": {
    "buildType": "apk",
    "gradleCommand": ":app:assembleRelease"
  }

Se a opção acima não funcionar (por depender de build type), a
alternativa é adicionar android:debuggable="true" no AndroidManifest
via config plugin. Crie um plugin novo em:

  artifacts/parallax-wallpaper/plugins/withDebuggablePreview.js

com este conteúdo:

  const { withAndroidManifest } = require('@expo/config-plugins');

  module.exports = function withDebuggablePreview(config) {
    return withAndroidManifest(config, async (config) => {
      const manifest = config.modResults;
      const application = manifest.manifest.application?.[0];
      if (application) {
        application.$['android:debuggable'] = 'true';
      }
      return config;
    });
  };

E adicione "./plugins/withDebuggablePreview" ao array "plugins" no app.json
APENAS se o EAS profile for preview. Se não houver forma condicional,
adicione permanentemente — vamos remover depois.
