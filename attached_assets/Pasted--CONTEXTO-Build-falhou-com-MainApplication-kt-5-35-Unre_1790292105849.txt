Causa: o plugin withParallaxLiveWallpaper.js injeta o import e a chamada
MobileAds.initialize(this) no MainApplication.kt, mas NÃO adiciona a
dependência play-services-ads ao módulo :app. A dependência existe no
módulo interno de react-native-google-mobile-ads, mas não é transitiva.

Fato observado: o build anterior resolveu play-services-ads-25.4.0.

Correção: estender withParallaxLiveWallpaper.js para também adicionar
a dependência ao android/app/build.gradle. Coeso — o mesmo plugin que
injeta o código passa a declarar a dependência.
