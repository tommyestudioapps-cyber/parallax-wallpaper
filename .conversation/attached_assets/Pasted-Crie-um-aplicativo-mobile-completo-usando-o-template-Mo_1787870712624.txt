Crie um aplicativo mobile completo usando o template Mobile App (Expo / React Native). O aplicativo deve funcionar 100% offline, utilizando AsyncStorage ou SQLite para gerenciar os estados locais e metadados das imagens. O objetivo principal do app é criar e aplicar papéis de parede com efeito Parallax 3D suave a partir de 3 imagens locais fornecidas pelo usuário.A arquitetura do aplicativo deve seguir estritamente as etapas e telas descritas abaixo:1. Gerenciamento e Compressão de Mídias (Back-end Local)Use bibliotecas como expo-image-picker para selecionar fotos da galeria do aparelho.Otimização Crítica: Assim que o usuário selecionar qualquer imagem, implemente uma rotina automática com expo-image-manipulator para comprimir e redimensionar a foto. O foco absoluto é desempenho: as imagens devem assumir o menor peso possível para evitar travamentos e lentidão na renderização do parallax.2. Tela 1: Importação e Edição Individual de CamadasCrie três espaços/quadrados separados e bem identificados na tela para carregar as fotos:Camada de Fundo (Background): Permite apenas edição simples de imagem (ajuste de brilho, contraste, saturação e filtros básicos de cores). Sem opção de corte.Camada Intermediária (Middle Ground): Permite a edição simples de cores/filtros + ferramenta de corte manual estruturada (Crop) para preparar a imagem antes de enviá-la para a IA nativa de corte de fundo (rmgb 1.4).Camada Frontal (Foreground): Mesmas funções da camada intermediária (Edição de cores + Ferramenta de corte/Crop preparatório).3. Tela 2: Montagem e Ajuste de Intensidade (Composição)Após o processamento individual, um botão avançará para a tela de composição de camadas:Exiba as 3 imagens empilhadas visualmente usando posicionamento absoluto (Z-Index).Adicione controles de toque simples (gestos de pinça/arrastar) para que o usuário possa selecionar de forma independente a imagem Intermediária ou a Frontal para ajustar livremente o tamanho (escala) e o posicionamento na tela.Insira um controle deslizante (Slider) horizontal para ajustar dinamicamente a Intensidade do Efeito Parallax.4. Tela 3: Preview Fluido e Aplicação NativaUm botão 'Visualizar' abrirá a tela de simulação final:Efeito Parallax Fluido: Implemente o movimento das camadas baseado nos dados reais do giroscópio/acelerômetro do celular (utilizando expo-sensors). A movimentação deve usar interpolação e suavização matemática rigorosa (animações desaceleradas baseadas em hardware). Movimentos bruscos ou grosseiros não são aceitáveis.Na parte inferior da tela de preview, exiba o botão 'Aplicar'.Ao clicar em 'Aplicar', utilize chamadas nativas do sistema Android para abrir a interface padrão do sistema operacional que permite ao usuário definir a imagem resultante para a 'Tela Inicial', 'Tela de Bloqueio' ou 'Ambas'.Permanência: Configure a estrutura técnica básica para garantir que o serviço de renderização do parallax permaneça ativo e persistente no sistema do telefone para que o papel de parede continue funcionando em segundo plano.Desenvolva uma interface limpa, moderna, em modo escuro (Dark Mode) por padrão, focando em feedbacks visuais fluidos para o usuário durante o corte e ajuste das imagens.
